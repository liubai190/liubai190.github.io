在这个乱糟糟的年头，我自认为还算简单专注，化用一句名言，就是将有限的精力投入到了无限的好奇与实践中去。无限的好奇与实践先不表，本文主要说管理有限精力的一些尝试。

## 1. 上网专用路由器

作为一个老派的网民，我至今依然保持着一项良好的习惯：移动数据随用随开，用完即关。当然，这是户外场景，在家里还是使用 WiFi 更为便利。但免费高速的 WiFi 往往伴随着另一个弊端——放纵。众所周知，克制作为一门艺术也是一种美德，但这种美德却往往沉沦于免费与便利。近 30 年的互联网、近3年的 AI ，无疑都是好东西，但我们往往沉溺其中。

为了将精力从过度的网络中抽离出来，我曾经买过一个路由器。我在家里弄了两个 WiFi，并且都在同一个房间里面，也就是我活动的屋子。家里的各种智能家居用一个，我的手机、平板等设备用一个，简直就是脱裤子放屁。不过这种方法，相当于是为我的室内 WiFi 添加了一个物理开关，路由器仅在需要的时候通电，用完即断电，和手机上面的移动数据一样。起初我以为这样会避免很多不必要的摸鱼行为，事实也确实如此。不过没几个月我就放弃了，原因未知，可以说是一项完全失败的实验，这也是为什么标题是“尝试”而非“方法”。

## 2. 摸鱼网站转 360 导航

如果说上一条是给互联网的房间加了把锁，那这一条就是给几个特定的柜子贴了个赛博封条。这个封条一旦撕开，柜子将会被强制传送到垃圾场，并且每一次传送都将为这个垃圾场增加点击和收入。这种行为杀敌 800 自损 1000，效果立竿见影，让我重拾了很多精力。

上面这段话似乎不知所云，有必要翻译一下：将以下这段脚本（由 AI 生成）加载到浏览器中就行了。它将把你指定的网站原地跳转到 360 导航，无过正不矫枉，以恶心 360 的方式一样恶心这几个网站，这样就不会有事没事都想着刷一刷了。当然，以上匹配我的冲浪场景仅对浏览器有效，如果习惯开 APP，那就得另请高明了。

```javascript
// ==UserScript==
// @name         屏蔽跳360主页
// @namespace    via.redirect.block
// @version      1.0
// @description  打开知乎(zhihu.com)/IT之家(ithome.com)自动跳转到360导航(hao.360.com)
// @author       Bai
// @match        *://zhihu.com/*
// @match        *://*.zhihu.com/*
// @match        *://ithome.com/*
// @match        *://*.ithome.com/*
// @run-at       document-start
// @grant        none
// ==/UserScript==

(function () {
    "use strict";
    // 页面加载前直接替换为360导航(hao.360.com)，不留返回入口
    location.replace("https://hao.360.com/");
})();
```

## 3. 微信专用手表

我没有戴表的习惯，但除了手机和平板，第三种能独立登录微信的设备，就是手表。为了在检查通知时只检查通知，我入手了儿童手表“米兔 4 Pro”，并为它装了两个应用：手表版蓝微信和 AnyLauncher。前者的作用是独立使用微信，后者的作用是把微信设为手表的启动器（Launcher），也就是系统桌面。然后通电通网，辅以 3D 打印的支架，一个带摄像头的“微信座机”便组装完毕。

这台座机有且仅有一个功能，就是使用微信，并且微信只有文字、语音和图片，检查消息时也可以简单回复。在避免分心这件事上，可以说是只有优点没有缺点。

## 4. AI 语音便利贴

又一个戒手机神器。在它之前，我将脑中一闪而过的念头记在纸上，等做完手中的事再去解决。当然，这只是理想情况，大多数情况都不会这么理想，难免会拿起手机，然后陷入时间的黑洞。但是这个东西极趣，语音便利贴不仅能靠大模型整理待办并到处同步，同时还附送一个 AI 对话的功能，基本可以覆盖脑中的 8 成念头，极大降低我打开手机的频率，堪称神器。

## 5. 平板只在有需要时开机

平板这东西对我个人算是鸡肋，使用场景极少。没有吧，感觉又缺一个应对性能的设备；但你说我有多少需要极限性能的场景？似乎也没有更多的意义，像是为了准备什么场景缓解焦虑的东西，这么看就有点消费主义的味道了。

又扯远了，总之对于非日常刚需的玩具，用的时候再开机，避免一拿起来又放不下。况且，这玩意儿（大我B7 Pro）续航实在太差，这样也能避免时不时就充电。

## 6. 动画片下载后观看

对于剧集视频，我一直不习惯在线看。究其根由，在线的视频永远看不完，无穷无尽，看完这个永远还有下一个，看完这部也还会有更新鲜、更好看的下一部。但离线视频不会，它们仅仅是一个又一个几百兆的二进制文件。当这些文件全部被读取并且播放完毕，这部作品就完成了它的使命，送到观众面前。没有弹幕，没有评论，更没有“播放你喜欢的”。我的使命就是从头到尾看完它们，或者中途放弃，记得起身到处转转，放空一下脑子，像看电影一样结束这个故事。

然后再找寻下一个故事~

## 7. 买个挂袋装手机、平板、阅读器

这条可以称之为“屏幕远离计划”。把这些屏幕挂在房间的另一个角落，而不是伸手可及之处，增加使用它们的物理和心理成本，从而更加专注手头的事。确实有需要网络的情况，联动第四条“语音便利贴”记个待办，又或者短暂的 AI 对话，都能抚平一些乱七八糟的念头。这套组合拳下来，平日里 10 成摸手机上网的冲动，几乎就只剩下 2 成。那这2层拿起手机又何妨？人终归是感性的动物，不是机器，大可不必执着于这些条条框框，完美无缺。

## 8. 手机不上床

这个习惯我保持了10年，如今哪怕是睡前看手机，我都会在书桌上把要看的看完，然后放下手机去睡觉。睡觉在我这儿有个明确的心理和生理状态间隔，上床就只有一件事：睡觉，没有二心。周末不想起床也就翻个身继续睡。极少数失眠的情况下，我依然不习惯玩手机，因为要起床拿很麻烦，而且有种破戒的失德感。

以上简单盘点了我在接触手机和网络方面的一些尝试，有的成功，有的失败，有的长期保持并获益匪浅，让我更加有精力专注于自己想干的事情。

这里再补充两点我的个人习性，算是我个人身上能进行这些尝试的基础条件：

**几乎没有什么朋友。**这点让我无需24小时联网。需要联网的情况大多是为了解决我的需求，满足各种好奇心，而非处理维护各种平台的社交关系。也就是说，我对网络的开关有极大的自主权，并不会因为长期（1天及以上）断网就错过什么或损失什么。倒不如说，断网对我的生活利大于弊。我的精力、注意力以及情绪，都将围绕我生活中的书籍、影视数据以及家务活动等实体运转，能够长期保持平和的心态。

**观察者而非参与者。**我对网络（乃至我自己）的态度，更多是观察而不是参与，对技术的理性与注意力的追求让我很难参与其中。弹幕看似热闹，实则是异步发言；你的困惑与解答，回应的人早已离场，而解答的人尚未到来；评论则会让人有一种等待点赞与回复的期许，这种期许则会进一步消耗未来某个时间点的注意力，其他场合大抵如此。网络对我而言，更多像是电视机而非游戏机，输入远远大于输出（这会儿在输出了），而这又反过来保证了我关闭电视机后的精力与情绪，不会被电视上的内容所左右——毕竟如有所相，皆是虚妄。
