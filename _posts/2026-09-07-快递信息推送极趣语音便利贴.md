前段时间入手了个极趣实验室的墨水屏AI语音便利贴，甚是好用。这玩意儿基本上是开源的，待办事项能在网页、小程序、手机（三方包）、Windows（三方包）之间同步，还能接AI助手。某天夜间突发奇想，既然它能连AI，那要是能把快递信息推上去，岂不美哉？

说干就干，经过一番折腾，果真能跑通，下面简单回顾：

## 准备

·墨水屏看板（申请api）
·AI助手（workbuddy）
·快递信息（单号人肉提供……）
这个跟AI掰扯了半天，同一个单号搜出来好几个快递……最后还是申请了快递100 的api搞定了

## 流程

·workbuddy 连接墨水屏
这个没什么说的，把设备api和文档链接一并发给它，完事儿
·申请快递100 api
瞎填一个公司名注册开放平台，在管理后台拿到api，发给AI
· 快递信息
纯手动。网罗各平台订单，按名称+单号发给它，AI查到地址后一并推到终端，一日一次，并标记昨日完成

## 推送逻辑（本段复制于AI助手）

每天 05:00 云端自动化触发

1. 读 config.json（包裹清单 + 凭证）
2. 快递100 API 查每个包裹（自动识别快递公司）
3. 提取「城市 + 最新状态」，判断是否已签收
4. 读本地状态文件 state.json：
   · 已签收的包裹 → 跳过（签收即停）
   · 昨天未完成的 → 标记完成
5. 生成看板文本（包裹名 + 城市）
6. 极趣云 API 推送到墨水屏
7. 写回 state.json（今日进度）

## 优缺点

优点：ELEGENT！実にエレガントだ！

缺点：快递信息要人工录入。理论上如果是菜鸟裹裹的api，它就能主动抓取商品及物流信息，但菜鸟的api 服务对个人关闭，果然做大生意的都看不上C端这点儿小钱。哦，还有一个坏消息，快递100 的api 得花钱。初始额度只有100条，按一个快递3天到第4天签收来算，20几个快递就用完了。api 基础查询套餐330元3500单，有效期两年，每次查询约1毛……

## 结论

玩玩儿得了，优雅可是要花钱的;)
