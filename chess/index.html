棋

四个象棋变体 · 都在浏览器里跑 · 纯静态、自写引擎、不用装东西

  • → 四界大战四人象棋 /chess4/ 红、蓝、黑、青四方混战，逆时针轮流走子，各带一个九宫。 多一条规矩：除将帅之外，没走动过的棋子不能被吃——想活命就得先走出去。 另三家都是电脑，三档难度，出手间隔 2～10 秒可调。
  • → 翻翻棋暗棋 /DarkChess/ 4×8 半盘，三十二子全扣着铺满。翻出的第一枚是什么颜色，你就是哪一方； 之后按 帅 › 仕 › 相 › 车 › 马 › 炮 › 兵 的等级大吃小——除了兵能吃帅、帅不能吃兵。 翻开之前谁都不能碰。人机 / 同机双人两档。
  • → 串串香暗棋连吃 /ChessChess/ 与翻棋同一副牌，但改到线的交点上，走法照搬象棋——九宫、河界、马腿、象眼一律不管。 吃子看走法不看大小，所以兵照样能啃车；翻开的子能顺着线一路串着吃，还可以拐弯， 吃到哪一步由你点。
  • → 中国象棋标准规则 /ChineseChess/ 正经的中国象棋，红先。人机对弈三档难度，也可以同一台机器两个人轮流下； 带悔棋、走法提示、音效开关。引擎是本站自写的 Alpha-Beta 搜索，着法生成过了 perft 校验。

四个页面相互独立，都是纯静态 HTML，没有框架、没有后端、没有第三方代码； 棋子和棋盘的画法是各家自己的事，音效是程序合成的。 共同的一点：电脑只知道你也能看到的东西——它不会偷看你扣着的子是什么。
